# Mi Emprendimiento Digital

Proyecto web responsivo desarrollado como parte de la construcción de portafolio digital y práctica de control de versiones con Git y GitHub.

## 🚀 Características
- **Navegación:** Menú principal con enlaces de desplazamiento interno.
- **Servicios:** Tarjetas informativas de servicios ofrecidos.
- **Testimonios:** Sección con opiniones de clientes.
- **FAQ:** Preguntas frecuentes organizadas con acordeones desplegables.
- **Contacto:** Formulario funcional con validación interactiva mediante JavaScript.
- **Navegación fluida:** Botón flotante para regresar al inicio con desplazamiento suave.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Maquetación semántica.
- **CSS3:** Estilos adaptables y diseño moderno.
- **JavaScript (ES6):** Interacción, validación de formulario y scroll suave.
- **Git & GitHub:** Control de versiones e historial de commits.
